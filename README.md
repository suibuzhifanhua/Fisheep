# Fisheep · 企业微信 AI 工作台

> 本地 LLM × 企业微信桌面自动化。一个 Windows 桌面程序，把企业微信变成你的 AI 工作台。

Fisheep 通过 CDP 连接**企业微信桌面客户端**，驱动本地或远程大模型完成批量任务：IT 月报审计、信息采集、知识库学习、定时任务调度。模型可以完全跑在本机，数据不出内网，隐私由你掌握。

## 核心特性

- **审计自动化**：批量处理分支机构 IT 月报（每轮 22 份），自动与 Excel 设备清单交叉验证，输出绿 / 红 / 待定三态结论，全程无需人工翻页对表。
- **双模型本地 AI**：小模型负责 agent 主循环与工具调用，大模型（judge）负责关键决策。兼容本地 Ollama / vLLM 与任何 OpenAI 兼容 API——接本地模型时，对话与数据完全不出本机。
- **技能与连接器生态**：内置技能（审计、信息采集、知识学习）可持续扩展；连接器对接外部服务；学习中心沉淀经验、越用越懂你的业务。
- **OCR 旁挂**：课件 / 扫描件文字识别，独立组件按需启用。
- **版本管理 + 一键回滚**：每次发版自动登记「源码快照 + 可执行文件备份」，设置页一键回退到任意保留版本。
- **安全优先**：配置使用 DPAPI 加密（跨机不可移植、非明文）；每次发布前对产物树做 PII 扫描（银行卡号等）；运行时带自检与自愈机制。

## 快速开始

### 环境要求

- Windows 10 / 11（x64）
- 企业微信桌面客户端（已登录）
- 可选：[Ollama](https://ollama.com)（本地模型）
- 可选：Python 3.13+（仅从源码构建时需要）

### 使用预构建版

从 [Releases](../../releases) 下载最新的 `Fisheep.exe`，双击运行。首次启动按引导配置模型（本地 Ollama 或远程 API）。

### 从源码构建

```bash
git clone <repo-url>
cd fisheep
pip install -r requirements.txt
python build.py --yes
```

构建完成后产物在 `dist/Fisheep.exe`。构建流程内置：版本自动递增、静态门禁、打包、frozen 冒烟（全部模块 import 验证）、前端资源逐字节一致性核对。

## 隐私与安全

| 项 | 说明 |
|---|---|
| 本地模型 | 接 Ollama / vLLM 时，全部推理在本机完成，无外部请求 |
| 配置加密 | 模型密钥 / 业务配置 DPAPI 加密存储，绑定当前 Windows 账户 |
| 发布前 PII 扫描 | 产物树全量递归扫描敏感数据模式，命中即拦截 |
| 会话数据 | 历史对话保存在本机「产物库」目录，发版时可归档保留 |

## 开发

- **测试**：`pytest tests`（全量套件，上千用例，0 失败才允许发版）
- **发版**：`python build.py --yes`——版本号自动 +1，走完整门禁链
- **维护**：`python build.py --gc`——构建垃圾回收（先列清单确认再清理）
- **版本历史**：见 [CHANGELOG.md](CHANGELOG.md)

版本号是**连续递增**的（每次发版 +1），从 v1.0.722 起有完整 git 历史；更早版本由产品内部机制管理。
