# docs/ — 企微伴侣文档索引

本目录存放**审查报告、架构说明、专题分析**类文档。版本变更记录见根目录
`README.md`（最近版本）与 `CHANGELOG.md`（历史版本）。

## 归档规则

- **优化审查报告**：每轮整体代码审查产出一份，文件名 `优化审查_<日期>.md`，
  列出发现的问题、严重程度、修复建议与处理状态。**修复完成后在报告里标注
  「已修 / 未修 / 不修（附原因）」**，便于后续回看。
- **专题报告**：针对某一子系统的深入分析（如 `dead_code_audit_*.md`、
  `agent-evaluation*.md`）。
- **archive/**：已归档的早期文档，只读留档，不再维护。
- 超过 6 个月未更新的专题文档移入 `archive/`。
